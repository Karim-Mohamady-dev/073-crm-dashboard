# لوحة إدارة علاقات العملاء — Pipeline CRM (073)

لوحة CRM تجريبية ثنائية اللغة (العربية RTL والإنجليزية LTR) مع مبدّل لغة يُحفظ في localStorage.

## المميزات
- خط مبيعات بخمس مراحل مع السحب والإفلات وأزرار نقل، وتغيير المرحلة من جدول جهات الاتصال.
- جهات اتصال مع بحث وتصفية حسب المرحلة، وإضافة جهة اتصال مع تحقق، وحذف.
- ملاحظات لكل عميل (إضافة وحذف) مع سجل أنشطة؛ جميع البيانات محفوظة في localStorage.
- إحصاءات (إجمالي جهات الاتصال، صفقات مفتوحة، قيمة الخط، معدل الفوز) وحالات فراغ.

## التشغيل
```bash
npm install
npm run dev
npm run build
```
